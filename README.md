# Azan Clock for Windows

Free, ad-free prayer times and desktop alarms for Windows.

**[Download for Windows](https://blank871.github.io/azan-clock/)** · [Release notes and files](https://github.com/Blank871/azan-clock/releases) · [Download statistics](https://blank871.github.io/azan-clock/downloads.html) · [Report a bug](https://github.com/Blank871/azan-clock/issues/new)

Choose a city in Japan or worldwide. Get automatic daily prayer times, Azan for all five prayers, and a separate Jamaat alarm at a fixed time or a delay after Azan. The app can start with Windows and stay in the system tray.

The EXE is portable. Save it in a permanent folder and double-click it. Keep the PC awake and signed in for alarms.

Prayer times by [AlAdhan](https://aladhan.com/prayer-times-api). The default adhan is by [Adam-synagda](https://commons.wikimedia.org/wiki/File:Beautiful_adhan.ogg), released under CC0. See the [privacy and credits page](https://blank871.github.io/azan-clock/privacy.html).
